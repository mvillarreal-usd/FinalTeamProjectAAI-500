# FinalTeamProjectAAI-500
Final Team Project for AAI-500 

Short Description of Your Project and Objectives: The objective of this project is to identify which variables are more strongly related to hospital readmissions. By analyzing the data, we can determine which factors may have a stronger connection to a patient being readmitted to the hospital. Later, we could use these variables to develop a program that could help predict the level of treatment a patient may need or the probability that a patient might fall ill based on symptoms, as well as identify possible relationships between certain symptoms and diseases.

Name of Your Selected Dataset: Diabetes 130-US Hospitals for Years 1999-2008

Description of Your Selected Dataset (data source, number of variables, size of dataset, etc.): 
The dataset represents ten years of medical information on diabetes and all the variables that healthcare professionals review when dealing with this disease. This dataset has over 100,000 inputs and 47 features, which we will be able to analyze and clean based on our needs.

URL for the selected dataset: https://archive.ics.uci.edu/dataset/296/diabetes+130-us+hospitals+for+years+1999-2008
